# display-hotkeys

Горячие клавиши для режима проецирования — то же, что меню **Win+P**, но сразу
нужный режим, без выбора стрелками:

| Клавиши | Режим |
|---|---|
| **Win + M + 1** | Только экран компьютера |
| **Win + M + 2** | Только второй экран |

Удобно, когда к ПК подключены монитор и телевизор: картинка перекидывается
одним сочетанием.

Нажимать так: зажать Win, зажать M, нажать цифру (верхний ряд или NumPad).
Если цифру не нажать — срабатывает обычный Win+M (свернуть все окна), так что
стандартное поведение не теряется. Win+Shift+M и прочие сочетания не трогаются.
Если переключиться не вышло (например, телевизор выключен) — системный «бип».

## Установка

```powershell
.\install.ps1
```

Прав администратора не нужно: скрипт добавляет программу в автозапуск текущего
пользователя (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DisplayHotkeys`)
и сразу её запускает. Убрать — `.\uninstall.ps1`.

## Как устроено

- `DisplayHotkeys.exe` — фоновая программа без окна, ~14 МБ ОЗУ. Низкоуровневый
  хук клавиатуры ловит Win+M+цифру и вызывает `SetDisplayConfig` с топологией
  `SDC_TOPOLOGY_INTERNAL` / `SDC_TOPOLOGY_EXTERNAL` — ровно то, что выбирает Win+P.
  Какой из экранов считается «экраном компьютера», решает Windows, так же как в Win+P.
- Чтобы после проглоченных M и цифры не открылся «Пуск», программа подаёт
  неназначенную клавишу (vkE8) при зажатом Win. Второй экземпляр не запускается.
- `DisplayHotkeys.cs` — исходник (C# 5); `build.ps1` пересобирает exe компилятором
  из .NET Framework 4, который уже есть в Windows, — ничего ставить не нужно.

## Ограничение

Программа работает без прав администратора, поэтому, пока активно окно,
запущенное от админа (Диспетчер задач и т.п.), Windows может не отдавать ей
нажатия.

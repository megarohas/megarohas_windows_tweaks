# fancontrol-quiet-fans

Тихий профиль вентиляторов через [FanControl (Rem0o)](https://github.com/Rem0o/FanControl.Releases)
для конфигурации MSI B450M MORTAR MAX (Super I/O **NCT6797D**) + Ryzen 5 3600 +
RTX 3060. Цель: в простое — почти полная тишина, под нагрузкой — уверенный обдув,
и никакой «пульсации» оборотов на секундных скачках температуры Zen 2.

## Философия

- **GPU-вентиляторы не трогаем вообще**: vBIOS-авто с fan stop (0 об/мин в
  простое) работает лучше любых кривых.
- **CPU-вентилятор** — кривая от Tctl/Tdie с тихим полом и агрессивным
  сглаживанием: Zen 2 даёт мгновенные скачки +15–20 °C на любой чих, без
  гистерезиса и задержек вентилятор «дышит». Отклик вверх 5 с, вниз 10 с,
  гистерезис 1 °C вверх / 4 °C вниз.
- **Корпусные** — от температуры **GPU** (главный нагреватель корпуса —
  видеокарта), пол 28 %: по замерам калибровки ниже ~26 % эти вентиляторы
  физически останавливаются, а владелец хочет, чтобы они всегда вращались на
  минимуме (~600–700 об/мин, на слух — тишина). Пол продублирован жёстким
  `MinimumPercent=28` на обоих каналах.

## Кривые

| CPU quiet (источник `/amdcpu/0/temperature/2`, Tctl/Tdie) | Case (GPU) (источник `NVApiWrapper/<gpu>/sensor/0`) |
|---|---|
| 30° → 12 % | до 57° → 28 % (пол) |
| 45° → 18 % | 62° → 32 % |
| 55° → 28 % | 70° → 45 % |
| 65° → 40 % | 78° → 58 % |
| 75° → 60 % | 85° → 75 % |
| 82° → 85 % | 92° → 100 % |
| 90° → 100 % | |

Каналы NCT6797D: `control/1` = CPU_FAN (735–1488 об/мин, физически не
останавливается), `control/2`/`control/3` = корпусные (старт 35 % / стоп 26 % —
пороги замерены калибровкой FanControl). Плавность: `SelectedCommandStepDown=3`
(медленный сброс оборотов).

## Автозапуск и живучесть

- Задача планировщика **`FanControl`**: при входе в систему, от имени
  пользователя с наивысшими правами, `FanControl.exe -m` (свёрнуто),
  **без лимита времени выполнения** (иначе планировщик убьёт процесс через
  стандартные 3 дня!). Регистрация — `register-autostart-task.ps1`.
- Конфиг живёт в `C:\Program Files (x86)\FanControl\Configurations\userConfig.json`;
  рядом лежит полный снапшот `userConfig.snapshot.json` — восстановление =
  скопировать на место (от админа, при закрытом FanControl) и запустить FC.
- До входа в систему вентиляторами правит BIOS-кривая — первые секунды загрузки
  шумят по-заводскому, это нормально.

## Грабли (сэкономят вечер)

- FanControl **пишет конфиг при выходе** — править файл руками только при
  закрытом FC, иначе он перезапишет ваши правки своим состоянием из памяти.
- Идентификатор температуры NVIDIA у родного плагина FC —
  `NVApiWrapper/<gpu>/sensor/0` (именно `sensor`, не `temperature`); Tctl
  Ryzen из LibreHardwareMonitor — `/amdcpu/0/temperature/2`. Кривая с
  несуществующим идентификатором не применяется (FC покажет ошибку при старте).
- `LibreHardwareMonitorLib.dll` из комплекта FC собрана под .NET 10 — Windows
  PowerShell 5.1 её не загрузит, перечислить сенсоры из скрипта не выйдет.
- Пороги старт/стоп FC замеряет калибровкой; пол кривой **выше** стоп-порога =
  вентиляторы гарантированно никогда не остановятся.

## Файлы

- `userConfig.snapshot.json` — рабочий конфиг целиком (кривые, каналы, калибровки)
- `register-autostart-task.ps1` — регистрация задачи автозапуска

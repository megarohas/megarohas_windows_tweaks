# display-fxaa-artifacts

Разгадка многолетней загадки: часть приложений на Windows выглядит «как
пережатый JPEG», а причина находится за одной галкой в панели NVIDIA.
Здесь — симптомы, диагноз, лечение и все ложные следы, чтобы вы не потратили
на это три года.

## Симптомы

- Отдельные приложения — Electron (Claude, GitHub Desktop, VS Code, Obsidian)
  и Flutter (LocalSend) — выглядят «пережато»: мыло, двоение текста, местами
  чётко / местами нет, полосами.
- Появляется **не сразу, а спустя время** после запуска приложения.
- Браузеры (Chrome/Firefox/Edge) при этом **идеально чёткие** ← главный
  сбивающий след!
- Артефакт виден **даже на скриншотах** — значит, рождается при отрисовке,
  а не в кабеле/мониторе.

## Причина

Глобальное **«Сглаживание — FXAA»** в Панели управления NVIDIA. Драйвер
применяет этот пост-фильтр ко всем D3D-приложениям, а Chromium/Electron и
Flutter рендерятся через D3D — FXAA «зажёвывает» их текст и тонкие линии UI.

Почему браузеры чистые: у NVIDIA есть **встроенные профили для chrome.exe и
других браузеров, запрещающие сглаживание**. Поэтому «в браузерах всё
нормально» ничего не доказывает — это и делает баг таким живучим.

## Лечение

Панель управления NVIDIA → Управление параметрами 3D → Глобальные параметры →
**«Сглаживание — FXAA» = Выкл** → Применить → **перезапустить пострадавшие
приложения** (эффект снимается только при пересоздании поверхности — без
перезапуска кажется, что «не помогло»).

Если FXAA нужен в играх — правильная схема: глобально Выкл, а включать
пер-игрово через «Программные настройки».

## Ложные следы (проверены и исключены)

| След | Почему не оно |
|---|---|
| MPO (`OverlayTestMode=5`) | отключение не изменило картину (у MPO свои похожие болезни — см. ниже) |
| Масштаб 125 % / DPI-переопределения | на 100 % мыло оставалось |
| Разгон видеопамяти | на стоковых частотах артефакт оставался |
| Монитор / кабель / YCbCr | артефакт присутствовал в скриншотах |
| ClearType | включён и исправен |

## Смежное: MPO

Похожие симптомы (мерцание, чёрные прямоугольники, артефакты кусками окна)
бывают и от Multi-Plane Overlay. Официальный воркараунд NVIDIA:
`HKLM\SOFTWARE\Microsoft\Windows\Dwm` → `OverlayTestMode` (DWORD) = **5**
+ перезагрузка; откат — удалить значение. Но сначала проверьте FXAA — он
вероятнее и дешевле.

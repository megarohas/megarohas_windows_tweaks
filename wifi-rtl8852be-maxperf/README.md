# wifi-rtl8852be-maxperf

Realtek RTL8852BE Wi-Fi 6 (PCIe, `VEN_10EC&DEV_B852`). Из коробки: просадки
пинга из-за энергосбережения, самопроизвольные перескоки между точками из-за
агрессивного роуминга, фризы на ASPM.

## Твики — `apply-wifi-tweaks.ps1` (от администратора)

1. **MSPower_DeviceEnable → False** — запрет отключения адаптера для экономии
   энергии (WMI `root/wmi`).
2. **PCIe Link State Power Management (ASPM) → Выкл** для AC и DC в активной
   схеме питания.
3. **RegRoamLevel → минимум** (первое значение, начинающееся с «1», из списка
   допустимых) — адаптер перестаёт рыскать по соседним точкам. Установка
   перепривязывает адаптер: Wi-Fi моргнёт на несколько секунд.

Скрипт идемпотентный: роуминг трогает только если он ещё не на минимуме.

## Драйвер

`netrtwlane601` **6001.15.165.3** из Microsoft Update Catalog (штатный
6001.15.124.0 от 2022 — заметно старее). Внимание: в 6001.15.165.3 ключ
роуминга переименован из `RegROAMSensitiveLevel` в `RegRoamLevel` — скрипт
ищет по-новому.

На моей машине откат драйвера после Insider-флайтов автоматически чинит
[boot-guard](../boot-guard/).

# debloat-win11-insider

Чистка дефолтного балласта Windows 11 на машине с Insider **Dev channel** —
один идемпотентный скрипт `apply-debloat.ps1` (запускать от администратора,
лог `apply-log.txt` пишется рядом).

Главное отличие от типовых «деблоат-гайдов»: **телеметрия Insider не трогается**.
`DiagTrack`, Compatibility Appraiser и `InventorySvc` обязаны жить, иначе
перестают приезжать флайты. Также сознательно не трогаются `SysMain`/`WSearch`
(на SSD вреда нет), GameInput (API контроллеров, нужен играм) и старые
VC++-редисты (нужны старым играм).

## Что делает

| Шаг | Действие |
|---|---|
| 1 | Удаляет ~25 дефолтных UWP: Solitaire, Bing News/Weather/Search, Get Help, Office Hub, People, To Do, Будильники, Карты, Звукозапись, Кино и ТВ, Clipchamp, Power Automate, Dev Home, Game Assist, Виджеты, Phone Link, Outlook + Почта/Календарь, обе Teams |
| 2 | Деинсталлирует OneDrive (клиент; локальная папка с файлами не удаляется) |
| 3 | Сносит мусорные программы (Freemake, «Помощник по установке Windows 11») |
| 4 | Отключает службы вендорского RGB/мониторинга (MSI Center / Mystic Light) и `MapsBroker` |
| 5 | Отключает телеметрия-задачи: CEIP, Feedback (Siuf), Error Reporting, Maps, SoftLanding-реклама, Firefox Default Browser Agent |
| 6 | Реестр: реклама/«предложения» — выкл; Edge не грузится при входе (Startup Boost + Background off политиками); Delivery Optimization не раздаёт обновления в интернет |
| 7 | Чистит автозагрузку: Edge-прелоад, Epic, GOG, огрызок OneDrive |

Списки — под вкусы конкретного владельца (например, Xbox/Game Pass, принтер,
RDP и Quick Assist здесь сознательно оставлены): правьте `$apps`, список служб
и Run-значений под себя.

## Известные грабли

- **PowerShell 5.1 и кириллица:** файл сохранён в UTF-8 **с BOM** — без BOM
  PS 5.1 читает скрипт как ANSI и кириллица ломает парсер. При правке сохраняйте
  кодировку.
- **`Get-AppxProvisionedPackage` может вернуть «отказано в доступе»** на свежих
  Insider-билдах даже от админа — тогда депровижн пропускается и очередной флайт
  может вернуть часть приложений. Лечение: перезапустить скрипт, он идемпотентный.
- **`HKLM\...\Dsh` защищён TrustedInstaller** на новых билдах — политика виджетов
  может не записаться. Некритично: пакеты виджетов всё равно удаляются.
- **Лаунчеры (Epic/GOG) любят возвращать себе автостарт** при следующем запуске —
  надёжнее выключить его ещё и в настройках самих лаунчеров.
- После прогона желательна перезагрузка; отключение Mystic Light может сбросить
  RGB-подсветку на заводское поведение (возвращается включением службы обратно).

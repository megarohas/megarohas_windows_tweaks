# tweaks-reassert

Философия: **каждый твик обязан кем-то перепрожиматься**. Insider-флайты и
большие обновления умеют тихо откатывать что угодно: драйверы — на
inbox-заглушки, advanced-настройки адаптеров — на дефолт, Fast Startup —
обратно во включённое, удалённые приложения — назад в систему. Разовая
настройка без сторожа — это настройка до первого крупного апдейта.

Карта «кто что сторожит» на этой конфигурации:

| Твики | Сторож |
|---|---|
| Драйверы BT/WLAN/LAN + их питание, [usb-maxpower](../usb-maxpower/), схема питания (suspend/LPM/ASPM) | [boot-guard](../boot-guard/) — SYSTEM-задача при старте +25 с |
| [system-perf](../system-perf/) + [debloat-win11-insider](../debloat-win11-insider/) | задача **Tweaks-Reassert** (эта папка) — при входе +45 с |
| Кривые вентиляторов ([fancontrol-quiet-fans](../fancontrol-quiet-fans/)) | задача FanControl при входе |
| Андервольт GPU | задача MSI Afterburner при входе (`/s`, применяет свой Startup-профиль) |
| ReBAR / XMP / PBO ([bios-b450m-mortar-max](../bios-b450m-mortar-max/)) | NVRAM BIOS — Windows не перетирает в принципе |

## Как устроено

- `reassert-at-logon.ps1` — обёртка: последовательно запускает идемпотентные
  apply-скрипты (system-perf, затем debloat), пишет лог с ротацией рядом с
  собой. Пути внутри — локальные для конкретной машины, поправьте под свою
  раскладку.
- `register-task.ps1` — регистрация задачи: при входе пользователя, задержка
  45 с (не мешать загрузке), наивысшие права, скрытое окно, повторные запуски
  игнорируются, лимит 20 минут.
- Прогон на «чистой» системе занимает секунды — работа появляется только
  когда что-то реально откатилось.

## Нюансы

- Выключенный Fast Startup (см. system-perf) гарантирует, что задачи «при
  старте» срабатывают при **каждом** включении, а не только при «Перезагрузке» —
  без него сторожа спят при обычном выключении/включении.
- SYSTEM-задачи (boot-guard) не видны в `Get-ScheduledTask` из-под обычного
  пользователя — проверять их существование нужно из-под админа.
- Идемпотентность обязательна: apply-скрипты молчат и ничего не перезапускают,
  если дрейфа нет — иначе сторож сам станет источником шума.

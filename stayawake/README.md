# stayawake

«Не спать» (`NeSpat.exe`) — крошечная утилита одним окном: пока окно открыто,
компьютер не уходит в сон и экран не гаснет. Закрыли окно — всё вернулось к
обычной схеме питания. Без настроек, без установки, без фоновых процессов и
трея — состояние всегда видно по самому окну.

## Как работает

- WinAPI `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED |
  ES_DISPLAY_REQUIRED)` — системе запрещается уходить в сон и гасить экран.
  Запрос переподтверждается каждые 30 секунд на случай сброса.
- При закрытии окна вызывается `SetThreadExecutionState(ES_CONTINUOUS)` —
  блокировка честно снимается.
- В окне: зелёный «пульс», статус и счётчик времени работы.
- DPI-aware (манифест + ручное масштабирование под 125 %/150 %).

## Сборка

Зависимостей нет — хватает компилятора C# из .NET Framework 4.x, который
есть в Windows из коробки:

```powershell
.\build.ps1
```
